
# AgriIntel-X

**Explainable Multimodal AI Platform for Soil-Aware Crop Yield, Risk and Farmer Profit Forecasting**

Primary pilot crop: **Chilli (Capsicum annuum)** · Target country: **India** · Initial pilot region: **Karnataka**

> ⚠️ **Important**: All data generated by this platform's demo generator is **SYNTHETIC** and clearly labelled. It must not be presented as real farmer data or used to draw scientific conclusions. AI-generated agricultural recommendations are decision-support tools and should be validated with qualified agricultural experts / local extension services.

--

## 1. Overview

AgriIntel-X combines **soil**, **weather**, **historical yield**, **crop/seed**, **fertilizer**, **pesticide**, **irrigation**, **disease**, **market price**, and **production cost** into a single AI decision-support prototype that produces:

- Crop recommendation

- Yield forecast (with uncertainty)

- Disease / risk assessment

- Cost, revenue and profit estimates

- Explanations (SHAP-style / natural-language)

- What-If scenario simulation

- PDF reports

- Research dashboard (model comparison + ablation)

It's designed as a PhD research platform that can grow into a real-world field deployment.

## 5. Quick Start (Windows)

Open **PowerShell** in the project root.

### 5.1 Create a virtual environment and install backend deps

```powershell

python -m venv venv

venv\Scripts\activate

pip install --upgrade pip

pip install -r backend\requirements.txt

```

### 5.2 Configure environment

Copy `.env.example` to `backend\.env` (or project root — the backend reads `.env`):

```powershell

copy .env.example backend\.env

```

Defaults use **SQLite** (`agriintel.db`) — no DB server needed.

### 5.3 Generate the SYNTHETIC demo dataset

```powershell

python scripts\generate_demo_data.py --rows 600 --out data\demo\agriintel_demo.csv

```

### 5.4 (Optional) Train a yield model on the synthetic data

```powershell

python ml\training\train_yield.py --csv data\demo\agriintel_demo.csv --out ml_artifacts\yield_model.joblib

```

If you skip this step, the backend uses a clearly-labelled **DEMO heuristic** yield model instead.

### 5.5 Start the backend

```powershell

cd backend

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

```

Backend: <http://localhost:8000> · Docs: <http://localhost:8000/docs>

### 5.6 Start the frontend (new terminal)

```powershell

cd frontend

npm install

npm start

```

Frontend: <http://localhost:4200>

### 5.7 First use

1. Open <http://localhost:4200>.

2. Click **Get Started** and register (any email + password ≥ 6 chars).

3. Create a **Farm** and a **Plot** under **Farms & Plots**.

4. Add a **Soil Test** under **Soil Health**.

5. Explore **Weather**, **Crop Recommend**, **Yield Forecast**, **Cost & Profit**, **Risk**, **What-If**, and **Research**.

## 7. Environment Variables

| Variable | Purpose | Default |

|---|---|---|

| `DATABASE_URL` | SQLAlchemy URL | `sqlite:///./agriintel.db` |

| `JWT_SECRET` | JWT signing key | dev-only default |

| `ACCESS_TOKEN_EXPIRE_MINUTES` | Token lifetime | `1440` |

| `CORS_ORIGINS` | Allowed origins (comma-separated) | `http://localhost:4200` |

| `WEATHER_PROVIDER` | `mock` or `openweather` | `mock` |

| `OPENWEATHER_API_KEY` | Only if using OpenWeather | empty |

| `MODEL_DIR` | Where trained artifacts live | `./ml_artifacts` |

## 8. API Reference (short)

Base prefix: `/api`

| Method | Path | Description |

|---|---|---|

| POST | `/auth/register` | Register (FARMER/RESEARCHER/ADMIN) |

| POST | `/auth/login` | Login → JWT |

| GET/POST | `/farms` | List / create farms |

| GET/POST | `/plots` | List / create plots |

| POST | `/soil-tests` | Create soil test |

| GET | `/soil-tests/{plot_id}` | List soil tests |

| GET | `/soil-tests/{plot_id}/health` | Soil health score |

| GET | `/weather/{plot_id}` | 7-day forecast + alerts |

| POST | `/crop/recommend` | Crop recommendation (DEMO heuristic) |

| POST | `/yield/predict` | Yield forecast with bounds |

| POST | `/disease/predict` | Disease detection (DEMO provider) |

| POST | `/profit/predict` | Cost / revenue / profit / ROI |

| POST | `/risk/predict` | Multi-dimensional risk |

| POST | `/what-if` | Scenario simulation |

| GET | `/reports/farm/{farm_id}` | PDF report |

| GET | `/research/metrics` | Research metrics (RESEARCHER/ADMIN) |

Interactive docs: <http://localhost:8000/docs>.
